Install

Ready in a minute

Android

  1. Download Fetchr-…-arm64.apk from the latest release. Use the -arm.apk only on older phones.
  2. Open it and allow "Install unknown apps".
  3. New versions install over the old one; your files stay.

iPhone

  1. On the iPhone, download Fetchr-…-ipa.zip from the latest release. Safari saves it to Files; tap it to unzip.
  2. Share the .ipa to eSign, or install it with Sideloadly from a computer.
  3. Keep Fetchr open while a download runs.
